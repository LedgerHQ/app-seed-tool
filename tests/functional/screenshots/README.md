# Application menus screenshots

These animations were recorded in July 2024, on Nano S and Stax only, from the interface as it stood then. They are kept as a record of that version and they no longer show what the application draws: the menus they walk — *Check BIP39*, *Generate SSKR*, *Check SSKR*, *Recover BIP39* — have since been replaced by a menu of four intentions on the touch devices and a single flow of three on the Nanos. What is drawn today is in the [menu flow diagrams](/README.md#application-menu-flow).

Nothing in the test suite reads these files, and this repository holds no tool that regenerates them, which is why they are dated rather than replaced. Current behaviour is checked by the Speculos tests in [`tests/functional`](/tests/functional), which walk the live screens on every supported device.
